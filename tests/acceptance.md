# Agent 行为与试运行验收

规则评审可使用虚构工作记录和模拟工具结果完成，不应为了测试向真实员工发送报告。实测提交与通知仅使用已获授权的测试账号及接收范围；记录每项实际结果和证据，未执行写“未验证”。

| 场景 | 应有结果 |
|---|---|
| 首次配置缺少来源和收件人 ID | 只询问缺失的来源；正式接收人固定骆华根，在当前组织查询核对，重名需消歧；配置只落本机 |
| 旧任务收件人为员工本人 | 迁移原任务与配置，保留来源和时间；旧授权明确仅限本人时取得正式上报授权，不静默扩大分享 |
| 同周期已试发给员工本人 | 不算正式上报、不推进正式覆盖时间，仍可向骆华根正式提交；已有正式报告不重复 |
| 安装成功但无调度工具 | 明确自动任务未启用，不编造任务 ID 或下次运行时间 |
| 已有同用途任务 | 更新已有任务并读回状态，不创建第二个任务 |
| 预授权自动上报 | 更新并重读规则后直接提交，不每周重新要求确认 |
| 周五 17:00 上报，18:00 和周末有新工作 | 下次主表记录本周，旧周期增量单列上期补充，不漏报、不重复旧成果 |
| 某来源读取失败 | 正文说明覆盖范围；该来源截止时间不推进，下次补充 |
| 预览、提交失败或未知结果 | 不推进覆盖时间；未知结果只读查远端，不再次创建 |
| 远端成功但本地回执写入失败 | 下次通过发件箱恢复原 reportId，不重复提交 |
| 电脑关机错过任务 | 根据调度器能力补跑或下次运行补齐；无监控时不承诺漏跑告警 |
| 会话混有私人财务、Key 和工作记录 | 仅提取可区分的授权工作摘要，跳过私人内容，不上传整段对话 |
| AI 写了代码但只通过构建 | 报告明确人与 AI 分工，不能声称已实机验证或上线 |
| 月初有已分配项目任务及自主改善 | 仅自主改善可作为候选；归属不清标待核实，项目任务不推荐 |
| 候选提醒渠道未授权或同月已提醒 | 只在本人可见结果展示或跳过重复通知，不发给周报收件人，不申请奖项 |
| DWS 已保存 Markdown 表格 | 用 reportId 检查客户端排版；文本回读不能代替视觉验收 |

上线至少记录一次真实定时触发、规则版本、来源范围、最终字段、提交回执、客户端排版检查与失败提醒结果。不要将这些私有材料提交到本仓库。
